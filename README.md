# Yuvraj's Digital Canvas

Create a modern, polished, fully responsive personal portfolio website for college assignment for Yuvraj Pareek, a B.Tech CSE 1st-year student at JECRC University. Build exactly four navigable sections: Home, About, Skills, Contact; sticky nav with smooth scrolling; navy/blue professional student-friendly theme; subtle load/hover animations; rounded cards and soft gradients. Use all supplied copy/details precisely: name, course, year, college, hometown Bikaner Rajasthan, email pareekyuvraj977@gmail.com, Home title and intro, About education/timeline, stated hobby/interests, stated About paragraph, skills with Learning/Beginner/Developing labels and no percentages, contact text/form/location/email, placeholder LinkedIn/GitHub buttons that do not invent URLs, and footer © 2026 Yuvraj Pareek | B.Tech CSE Student | JECRC University. Make the Home profile photo area prominent in a professional circular/softly rounded frame using a clean clearly replaceable placeholder until the user uploads their actual photo. Ensure excellent mobile/tablet/desktop responsiveness and that it looks genuine rather than overly flashy/corporate.
